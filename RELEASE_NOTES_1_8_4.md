# Descargador de Música Accesible 1.8.4

Esta versión mejora cómo se instalan las actualizaciones del programa: ahora se descargan solas, sin interrumpir lo que esté haciendo, y solo se pregunta una vez que ya están listas para instalarse.

## Actualizaciones más simples y silenciosas

- El programa ahora descarga las actualizaciones automáticamente, en segundo plano, sin preguntar nada primero.
- Recién cuando la descarga termina aparece un único cartel con las novedades de la nueva versión y los botones Aceptar / Más tarde. Al elegir Aceptar, la actualización se instala de inmediato, sin una segunda confirmación.
- Si elige Más tarde, el archivo descargado se borra automáticamente.
- Si la descarga no se puede completar por una conexión lenta o inestable, el programa lo vuelve a intentar solo cada pocos minutos, sin mostrar avisos molestos.
- La revisión de actualizaciones ahora, de forma predeterminada, se hace al iniciar el programa en lugar de una vez por semana (se puede cambiar desde Herramientas > Opciones).

## Otros cambios

- Se corrigió un problema por el cual, después de aplicar una actualización, podía quedar sin borrarse el archivo ZIP descargado (de casi 200 MB) en una carpeta temporal del sistema.
