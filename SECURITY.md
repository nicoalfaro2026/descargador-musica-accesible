# Seguridad

## Falsos positivos de antivirus

No se debe pedir a los usuarios que desactiven Windows Defender u otro antivirus. Si una versión es detectada, registre la versión exacta, el nombre de la detección y el hash SHA-256 del archivo, y revise el paquete antes de recomendar cualquier excepción.

## Información sensible

No publique cookies, tokens, contraseñas, archivos de configuración personales ni logs que contengan datos que no se desee compartir.

## Releases

Se recomienda publicar cada ZIP portable acompañado de su SHA-256. La firma digital del ejecutable es recomendable cuando el proyecto disponga de un certificado adecuado.
