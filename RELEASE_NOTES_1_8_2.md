# Descargador de Música Accesible 1.8.2

Esta versión amplía el manual de usuario y mejora la accesibilidad y la traducción del aviso de actualización.

## Manual

- La sección de autenticación con cookies.txt solo explicaba cómo obtenerlas con Google Chrome y Mozilla Firefox; ahora incluye pasos propios para Google Chrome, Microsoft Edge, Brave, Vivaldi y Opera, además de Firefox, ya que la aplicación admite todos esos navegadores.
- Microsoft Edge requiere habilitar antes "Permitir extensiones de otras tiendas"; Opera requiere instalar antes su propia extensión puente "Install Chrome Extensions". Ambos pasos quedan explicados en el manual.
- Se agregó una nota para quienes usan otro navegador basado en Chromium no listado explícitamente.
- Los PDF de los seis idiomas se regeneraron a partir de los .txt actualizados para que ambos formatos queden siempre sincronizados.
- Se eliminó un manual duplicado que existía suelto en la raíz del proyecto y que el programa nunca llegaba a abrir.

## Ventana de actualización disponible

- La ventana que pregunta si se desea descargar una actualización del programa ahora muestra la lista de novedades de la nueva versión en un cuadro de texto de solo lectura, que se puede leer con las flechas arriba y abajo.
- El foco inicial se ubica en ese cuadro de novedades; con Tab se llega al botón "Aceptar" (descarga la actualización) y luego a "Más tarde".
- Toda esta ventana (título, aviso, cuadro de novedades y los dos botones) se traduce al idioma que la persona usuaria tenga elegido en el programa.
- La ventana "Actualización completada", que se muestra después de instalar la actualización, también incluye ahora las novedades de esta versión.
